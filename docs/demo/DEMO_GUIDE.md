# Local demo guide

Run the local services documented in README. Use fictional local accounts; email auto-confirm is local only.

Memory Vault: log Fight Club with a private neon-window memory, search `neonn`, edit it to a lighthouse, search again, then delete and verify disappearance.

Taste Timeline: log a 3-star viewing, add a 5-star reflection without a viewing, compare Then Me / Now Me and refresh.

Spoiler Safe: author a three-layer review in a second account; follow them from an unwatched reader. Inspect the safe feed, log the film, inspect post-watch text, explicitly open deeper reflection and refresh. The browser suite checks response bodies as well as DOM content.

These journeys are automated in frontend/tests/e2e/journeys.spec.ts. No timed presentation or public deployment is claimed.
