# Pain validation

Observed: Trakt's official notes announcement records demand for notes on more activity types (https://forums.trakt.tv/t/personal-notes/16308). Its ratings-page request records demand for filtering and access to prior ratings (https://roadmap.trakt.tv/p/full-featured-ratings-page).

Inferred: recording is useful only if old personal context and opinions are retrievable. This supports testing private memory search and explicit opinion history; it does not prove adoption or willingness to switch.

Hypotheses to validate: optional structured memories improve later recall; comparisons make opinion change understandable; separately authored review layers permit safer pre-watch recommendations. No fabricated user interviews, retention metrics, or guarantees of spoiler-free author text.
